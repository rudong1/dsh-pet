# 二形态剧情预览草稿

下载 `second-form-story.html` 到本地后直接打开；或下载 `pet-animation-draft.zip`，解压后打开其中的 `index.html`。不要在 GitHub 文件源码页面直接预览。

图片已全部内嵌在 HTML 中，不依赖 assets 文件夹、不需要联网或安装前端依赖。字幕使用正式版风格的白描边，随人物布局，始终位于人物上方。

包含 7 张 RGBA 人物素材和 8 幕剧情：喊用户上班 → 关心询问 → 用户表白 → 惊讶 → 确认 → 深呼吸 → 抱信 → 递信。

支持播放、暂停、重播、逐幕切换、进度条，以及棋盘/深色/白色背景检查。

这是尚未接入 DSH 插件的调试草稿。素材边缘仍有杂点，补绘的服装细节尚未统一；当前采用关键姿势淡入淡出，尚未完成逐帧补间。原插件代码和 main 分支均未修改。

验证：原播放控件检查通过；独立 HTML 在断网、无 assets 目录的隔离页面中，所有图片和 8 幕字幕布局通过 1280×900、390×844、800×500 三种尺寸检查。当前自动化浏览器策略禁止 file:// 导航，因此未宣称直接文件导航已验证。

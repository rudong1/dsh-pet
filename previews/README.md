# 二形态剧情预览草稿

下载本目录的 `pet-animation-draft.zip` 并解压，打开 `pet-animation-draft/index.html` 即可查看。也可在解压后的目录执行 `python3 -m http.server 8766`，使用本机浏览器访问对应服务。

预览包含 8 张透明 PNG 人物素材、9 个剧情节点，以及播放、暂停、重播、逐幕切换和背景检查功能。不需要安装前端依赖。

剧情：喊用户上班 → 关心询问 → 用户表白 → 惊讶 → 确认 → 深呼吸 → 抱信 → 递信 → 并肩作战。

这是未发布的美术和剧情调试草稿，尚未接入 DSH 插件。人物边缘仍有杂点，各帧补绘的服装细节尚未统一；当前采用关键姿势淡入淡出，尚未完成逐帧补间。请勿当作正式版本。

原插件代码未修改。预览播放器已通过图片加载、完整剧情播放、暂停、重播、逐幕切换、进度和背景控件的浏览器验证。

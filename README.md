# dsh-pet

跑在 DSH Web UI 里的浮动桌宠。每次进入 DSH 切换形态，点击切换状态，长时间不动会自己睡着。

## 安装

把下面的地址粘贴到 DSH 的 Plugin Manager 安装入口：

```
https://github.com/rudong1/dsh-pet/archive/refs/heads/main.tar.gz
```

装好后桌宠出现在界面左侧，可以随意拖动，位置会被记住。

## Windows 独立桌面版

不运行 DSH 也能使用桌宠，右键可切换形态、查看帮助或退出；托盘还支持显示／隐藏、置顶和可选开机启动。下载、运行和打包方法见 [桌面版说明](desktop/README.md)。原有 DSH 插件安装方式保持不变。

## 互动玩法

两个形态都支持以下互动：

- 点击桌宠互动区域的上半部（顶部 45%）：摸摸头，出现专属台词和轻轻压扁的动画。
- 相邻点击间隔不超过 0.9 秒时，第二下会嫌弃，第三下起会生气并抖动。头部和身体的点击都会累计；慢慢摸头不会惹它生气。
- 停手约 4 秒后恢复之前的状态；点击身体仍可切换原有状态。
- 拖动不算戳击；睡着后点击可以唤醒并互动。

当前互动复用各形态现有图片。后续可加入 `mint-pet.png`、`mint-annoyed.png`、`mint-angry.png`，以及对应的 `alt-*.png`，再运行 `python tools/embed-art.py` 嵌入。专属图片会优先显示，未添加时使用当前的替代表情。

### 桌面版 v0.4.0 特殊动作

二形态使用新的透明常态立绘。右键或托盘选择“工作ing”或“表白”，播放一次后保持最后一帧；再次点击同一项恢复常态。两个动作可以互相切换，切换形态也会退出。保持期间可以拖动，普通点击和闲置睡眠不会打断。

安装版右键选择“检查更新”即可更新；首次使用到 [Releases](https://github.com/rudong1/dsh-pet/releases/latest) 下载 Windows `.exe` 安装包。

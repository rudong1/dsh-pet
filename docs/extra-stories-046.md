# v0.4.6 新动作

用户授权新增一形态两段、二形态两段并发布，连同此前已经接入本地的“偷吃”一并纳入。

| 名称 | 形态 | 四幕剧情 | 结束画面 |
| --- | --- | --- | --- |
| 摸鱼被抓 | 一形态 | 瞌睡 → 惊醒 → 装忙 → 卖萌 | 求放过 |
| 鲸鱼快递 | 一形态 | 等待 → 收包裹 → 拆出小鲸鱼 → 抱住 | 抱紧小鲸鱼 |
| 咖啡加油 | 二形态 | 犯困 → 端咖啡 → 递给主人 → 打气 | 举拳加油 |
| 晚安守候 | 二形态 | 看时间 → 准备毯子 → 盖好 → 晚安 | 抱着鲸鱼靠枕 |

`desktop/extra-sequences.mjs` 配置剧情、台词、时长和轻微动作；每段四个关键姿势，以淡化、位移和缩放衔接。每段一次性播放，保持末帧，点击或菜单退出，拖动、摸头和闲置睡眠不会打断保持。

原始生成图集在 `assets/animations/{mint-slack,mint-parcel,alt-coffee,alt-goodnight}/sheet.png`。配套 `desktop/*-poses.mjs` 保存 SHA-256 和 SVG 轮廓，完整保留越过格子的发梢或道具，不裁切图片像素。`tools/atlas-display-clips.py` 仅只读分析 PNG alpha，生成显示轮廓；需要 Pillow、NumPy、SciPy。构建与运行直接使用预计算数据，无需安装 Python 依赖。

角色高度分别为一形态 154px、二形态 320px，和既有常态与特殊动作匹配。台词独立于镜像层，尊重系统减少动态效果的设置。

真实 Electron 桌面测试覆盖所有新剧情阶段、末帧保持、字幕可读及人物点击／菜单退出。可设置 `PET_VISUAL_DIR` 输出各幕原生窗口截图供检查。CI 桌面测试超时由六分钟延长至十分钟，以容纳十段动作的真实时间播放检查；仍要求 Windows 打包与测试均通过才发布。

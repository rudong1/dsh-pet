# 形态一：伪装 Claude（v0.4.4）

基于用户提供的五张参考图：蓝色大肥鱼看伪装书、橙色 Claude 看另一册书、疑惑抱着橙色大肥鱼、东张西望、喜爱地抱紧。作为形态一特殊动作“伪装 Claude”，仅在当前为形态一时显示。

六张独立 RGBA 素材在 `assets/animations/mint-claude/`，七个阶段由 `desktop/mint-claude-sequence.mjs` 配置：

1. 蓝色大肥鱼看书，CSS 小幅摇头晃脑。
2. 联想：保留看书姿势，出现思考提示。
3. 橙色 Claude 看另一册书。
4. Claude 疑惑地抱着橙色大肥鱼小人偶。
5. 向左看。
6. 向右看。
7. 喜爱地抱紧，保持最后一帧。

整段约 15.9 秒，最后一次性保持，不循环；点击末帧人物或再次点菜单恢复形态一常态，勾选同步取消。普通表情轮换不会进入此动作；切换形态会退出。

背景透明，补全手、裙摆、鞋、头发等原图没有展示的轮廓。小人偶按用户要求同为铜橙配色。书封无文字，两个书名在独立字幕层显示，左右翻转不会镜像文字。图像原样等比显示，不裁边；六张图的 alpha>32 轮廓均不接触画布边缘。

当前为生成关键姿势配合 CSS 晃动、位移和淡化组成的草稿，不是逐帧光流补间。看书用 Q 版造型，联想中的拥抱沿用成人造型，是根据原参考图的画面转换。整体高度仍匹配一形态常态。

离线预览：先执行桌面 build，再运行 `python tools/package-peek-preview.py --name mint-claude-preview --action claude --only-selected`。ZIP 解压后打开 HTML，此精简包只内嵌本段素材，不带其他动作。此前仅提供独立预览；本轮经用户授权纳入 v0.4.4 正式版。

字幕配色：大肥鱼看书和联想阶段保持蓝色；从 Claude 看书到抱紧的五个阶段改用橙色，保留白色描边，镜像时仍可读。

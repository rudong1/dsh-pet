# 形态一特殊动作：要饭（v0.4.5）

用户 ZIP 含两张 JPG：坐着捧空金属碗、站着委屈看主人。仅按图像内容作为参考，没有附带文档指令。参考文件保留在开发目录；角色和动作由图像工具重新生成独立透明 PNG，补全耳朵、头发、裙摆、手脚、尾巴和碗边。

五张素材在 `assets/animations/mint-rice/`，六个阶段由 `desktop/mint-rice-sequence.mjs` 控制：捧碗讨饭 → 再求一碗 → 主人给苹果 → 盯着苹果发愣 → 站起来开闹 → 坐下继续闹。苹果从收到时起一直留在碗里；没有真的变成米饭或被扔走。

文字独立于图片显示，面向左时不会镜像。高度 154px，与形态一常态相近。站起和坐下用独立姿势淡化衔接，开闹加有限次数的抖动，结束后停在最后的委屈表情，不会无限抖动。全部画布等比显示，不裁切。

“要饭”只出现在形态一右键和托盘菜单中，普通点击轮换不包含它。结束后点击人物或再次选择同一菜单项恢复形态一常态，菜单勾选同步清除；保持期间可拖动、不会闲置睡眠。切换形态退出当前特殊动作。

预览导出：`npm run build --prefix desktop` 后执行 `python tools/package-peek-preview.py --name mint-rice-preview --action rice --only-selected`。解压 ZIP 后打开 HTML，无需安装桌宠。当前是五个生成关键姿势搭配位移、淡化、抖动组成的草稿，不是逐帧光流补间。

此前仅提供离线预览。本轮经用户授权纳入 v0.4.5 正式版。

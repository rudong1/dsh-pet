# 形态一特殊动作：哈~（v0.4.4）

用户三张参考图：问午饭、弯下腰哈气、抱着小鲸鱼。去掉原图文字和背景，根据参考生成五个独立透明姿势，补全耳朵、头发、裙摆、手、双腿、鞋和尾巴。小鲸鱼是独立蓝白色伙伴，和人物自己的深蓝尾巴区分。

右键或托盘选择“哈~”，自动进入一形态，播放：

1. 问中午吃什么（2 秒）。
2. 小鲸鱼出现（1.6 秒）。
3. 弯腰凑近（1.1 秒）。
4. 哈气（1.6 秒，独立 CSS 呼气效果）。
5. 抱起小鲸鱼（2.2 秒后继续保持此帧）。

结束保持期间可拖动、不睡眠。左键点击人物或再次点击“哈~”恢复一形态常态，菜单勾选同步清除。切换形态或选择其他特殊动作会退出当前动作。普通点击轮换不包含此特殊动作。

素材：`assets/animations/mint-ha/`；时长、台词、位移和呼气位置：`desktop/mint-ha-sequence.mjs`。以 154px 高度容器显示，站立人物的可见高度与一形态常态约 147.5px 接近；弯腰、趴低的高度随姿势变化。图片整张等比显示，不切图、不裁边，字幕独立于镜像层。

当前是五个生成关键姿势加淡化、位移组成的草稿，不是逐帧光流补间。五张 PNG 的 alpha>32 轮廓均不接触画布边缘。

本地执行 `npm start --prefix desktop`，从右键菜单预览。“工作ing”“表白”以及它们的末帧点击恢复修复继续保留。此前仅作草稿；本轮经用户授权纳入 v0.4.4 正式版。

## 下载预览与菜单筛选

`python tools/package-peek-preview.py --name mint-ha-preview --action ha` 导出独立离线 HTML/ZIP。预览可切换多个动作、左右朝向、重播，点击收尾人物可恢复常态。正式应用的右键与托盘菜单按当前形态过滤：一形态为“伪装 Claude”“哈~”，二形态仅“工作ing”“表白”；切换形态退出旧动作。预览文件可独立下载；v0.4.4 包含完整应用改动。

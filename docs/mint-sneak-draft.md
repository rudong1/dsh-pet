# 形态一特殊动作：偷吃（v0.4.6）

沿用用户已看过的《嘴硬的小馋鱼》六连图与连续预览：嫌弃苹果 → 肚子饿 → 偷咬一口 → 被发现 → 藏苹果 → 红着脸分你一口，约 14.1 秒。

“偷吃”仅在形态一的右键和托盘菜单中显示，普通点击轮换不会进入此动作。播放结束保持“分你一口”；点击人物或再次选择同一菜单项恢复形态一常态，勾选同步清除。保持期间可拖动、不睡眠。偷咬阶段点击人物可提前触发“被发现”；切换形态退出动作。

- `assets/animations/mint-sneak/sheet.png` 原样保存生成的透明六连图。
- `desktop/sneak-poses.mjs` 记录源文件 SHA-256、各姿势的取景框和 SVG 轮廓。轮廓由原 PNG alpha 只读分析得到；完整保留跨越格子边缘的发梢、尾巴和鞋，不修改素材像素，不把相邻帧碎片带入。
- `desktop/mint-sneak-sequence.mjs` 配置动作、台词和时长，沿用已预览的晃动、惊跳、藏苹果和递苹果过渡；这是六个关键姿势加代码动作，不是逐帧光流补间。

显示容器高 154px，与一形态常态匹配；台词独立于镜像层。SVG 按完整取景框等比显示，沿用普通 PNG 动作的淡化和一次性播放逻辑。

本地执行 `npm start --prefix desktop`，切到形态一后右键选择“偷吃”。离线导出：桌面 build 后运行 `python tools/package-peek-preview.py --name mint-sneak-preview --action sneak --only-selected`。

此前仅作本地接入；本轮经用户授权与四段新动作一同纳入 v0.4.6。
